# SatisCorp
Welcome to satiscorp official GitHub organization, Here we will post new tools, and host mirrors of other satiscorp tools. SatisCorp is fully AI free so we dont support AI in any of our tools and we do not support AI development in any of out repos.
Also we dont support telemetry trackers in tools, Cloud connections or cloud accounts, that is why our tools work perfectly fine without any internet or account. Older satiscorp tools and apps were made by user [@gtref](https://github.com/gtref) and contained
the `satis` key word. 

## Current tools

Currently we have 3 tools.

- [satiscode](https://github.com/gtref/satiscode)
- [SatisDocs](https://github.com/gtref/satisdocs)
- [SatisTimer](https://github.com/gtref/satistimer)
